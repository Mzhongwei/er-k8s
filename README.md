## Installation
To set up the EAER-K8S environment locally, you will need to have Docker and Minikube installed. Follow the instructions below to get started:
1. Clone the repository:
   ```bash
   git clone
    ```
    cd eaer-k8s
2. Build the Docker image:
   ```bash
    docker build -t eaer-k8s:latest .
    ```
